# 阶段 4+：对话输入能力——多图上传/粘贴 + 文件上传 + 细节修复

> 一句话：对话输入区支持**多图（上传/粘贴，最多 9 张）+ 文件（文本/代码/PDF/Word 提取内容）**，
> 图片自动路由视觉模型、文件内容随问题进上下文；顺带修了预览遮挡、中文名乱码、下拉溢出。

## 一、多图（图片）

- **上传**：输入框左侧图片按钮，可多选（`multiple`）；**粘贴**：剪贴板多张图片全部收集；
- 统一走压缩链路（最长边 1024 / JPEG 0.8），上限 9 张（`MAX_IMAGES=9`，后端 `@ArrayMaxSize(9)`）；
- **预览置顶**：待发送图片在输入框上方横排展示，每张可单独移除，计数 `N/9`；
- 发送：`imageDataUrls` 数组 → 后端视觉消息格式（content 数组多张 `image_url`）→
  自动路由视觉模型识别；消息落库新增 `chat_messages.image_data_urls`（JSON 数组，兼容单图字段）；
- 历史消息多图网格渲染。

## 二、文件上传

- 新增 `POST /chat/extract-file`：multipart 上传 → 按类型提取文本
  （文本/代码直接读，PDF/Word 抽取文字）→ 返回 `{ filename, content, truncated }`；
- 文本上限 **3 万字符**自动截断（`MAX_FILE_CHARS=30_000`）；不支持的二进制（exe/zip/视频等）与空文件拒绝；
- 前端：文件按钮选择（最多 5 个，`MAX_FILES=5`）→ 提取 → 文件名 chips 预览可移除 → 发送时内容拼进消息
  （`【上传文件内容】`块）；用户消息里文件内容**默认折叠**展示（点击展开）；
- 中文文件名修复：busboy latin1 乱码 → latin1→UTF-8 还原（与知识库上传同法）。

## 三、细节修复

| 问题 | 修复 |
|---|---|
| 图片移除按钮被上方工具行挡一半 | 按钮改到图片内部右上角（不再越出滚动容器） |
| 只有文件（无图片）时预览栏消失 | 预览栏条件改为 `图片 || 文件` |
| 模型下拉淹没屏幕外 | 高度估算计入推理等级分区 + `max-h-[70vh]` 内部滚动 |
| API Key 输入弹"保存密码" | 密码类型输入框默认 `autocomplete="new-password"` |
