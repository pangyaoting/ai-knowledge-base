## 二、最终实现速览（当前 HomeCosmos.vue）

### 2.1 黑洞（暗色）
- **吸积盘**：1100 粒子，开普勒轨道 + 缓慢内落（vr −0.0001~−0.00034），`diskColor` 内白热→金黄→橙→品红→蓝紫；
- **吸入粒子 infall**：160 个，径向快速坠入（默认 −0.0007~−0.0015，重生重置），与盘同款配色/多普勒/光晕；
- **鼠标互动**：局部（`localPull`，约 0.16·min(w,h) 半径）粒子加速旋转 + 加速吸入；悬停核心（2.5R 内平滑增强）→ 全部粒子加速旋转、加速坠入视界（vr 下限 −0.025 防爆炸）。

### 2.2 白洞（浅色）
- **背景**：以白洞为圆心的径向渐变，核心周围深蓝 `#2c4a80`（0.18 半径内）→ 快速过渡 → 边缘白，保证文字可读；
- **喷流**：2400 粒子，默认缓速 0.0035~0.0065（约 4.5s 一轮），`whJetColor` 纯白→冷白→淡蓝→蓝紫→深蓝紫（全程冷色调）；
- **鼠标互动**：悬停核心（2.5·coreR 内）全体加速，封顶 vr 0.028（约 1s 一轮爆发）；能量斥力保留；
- **连续性**：粒子 `age` 淡入（0.25s 涌现）→ 全程饱满不渐隐 → **飞出屏幕 20px 才循环重生**（屏幕内永不消失，重生发生在不可见处）。

### 2.3 两套互动的对称设计（面试可讲）
| | 黑洞（暗色） | 白洞（浅色） |
|---|---|---|
| 默认 | 缓慢吸入 | 缓速喷射 |
| 悬停核心 | 全体加速吞噬 | 全体加速爆发 |
| 颜色 | 内白热 → 外蓝紫 | 内纯白 → 外深蓝紫 |
| 生命周期 | 坠入视界即重生（盘）/ 出屏重生（云） | 出屏重生 |

## 三、关键决策与原理

1. **"不明显"的根因是对比度**：白色粒子在浅蓝天空上色差仅几个亮度级 → 第 8 轮起给白洞上深色背景（先上浅下深，后改核心深蓝径向渐变），白色粒子在深蓝底、深蓝紫粒子在白底，全程互补；
2. **暖白 ≠ 白色**：`[255,244,224]` 炽白在深蓝底上被感知为赤橙（用户："滚烫吗"）→ 白洞全程改纯白冷色渐变，光晕/反光子环同步去暖调；
3. **连续性 = 重生发生在不可见处**：`age` 淡入让核心重生点 alpha≈0；外圈不渐隐则必须**飞出屏幕才循环**，屏幕内全程可见；
4. **初始鼠标在屏幕中央会误触发互动**：粒子铺满整页 + 鼠标初始 (0.5,0.5) → 页面刚打开中央粒子就被局部引力加速 → `mouseActive` 门控修复；
5. **白洞=黑洞时间反演，互动也要对称**：黑洞"吞噬"（悬停全体吸入）、白洞"爆发"（悬停全体喷射），参数一一对应（2.5R 阈值、vr 封顶、生命周期）——用户接受度高、代码也好讲。

## 四、坑（本轮新增）

1. **esbuild 数字字面量改写**：`0.0028` 在 vite 转译后变成 `28e-4`，用字符串匹配验证热更新内容时会误判"没更新"——检查 `rand(0.00x,...)` 要在源码 grep，不要在后端返回的模块里匹配；
2. **vite watcher EBUSY**：编辑工具经临时目录写文件触发 `EBUSY: resource busy or locked ... tmpdir`，vite 崩溃——改完文件后需重启（后台 `npx.cmd vite --host`，需完整权限）；
3. **vr 累积爆炸**：鼠标持续压核心时 `vr` 每帧累加，需设下限/封顶（黑洞 −0.025、白洞 +0.028），重生时重置默认值；
4. **换色板要清引用**：删 `WH_JET_PALETTE` 后必须同步清 `WhDiskParticle.color` 字段与光尘颜色，否则 `vue-tsc` 报未定义。
