# 阶段 4+：会话推理等级（Off/高/最高）+ 对话图片上传 + 整理预算同步

> 一句话：模型下拉里加了第二个入口——**推理等级**（关闭/高/最高，中文）；
> 对话支持**选择本地图片**上传（不再只有粘贴）；自主研究"报告整理"预算显示同步为 12k。

## 一、推理等级

- **是什么**：DeepSeek V4 系列是推理模型（回答前先"思考"，思考 token 计入费用）。
  `reasoning_effort` 控制思考强度：**等级越低越省 token、越快**；越高越准但越贵越慢；
- **Off 的含义**：关闭推理（不思考直接答，最快最省）。DeepSeek API 不接受 `off` 值
  （实测 400），推理是模型内建的关不掉 → "关闭"映射为**最低档 `low`**（几乎不思考）；
- **存储**：`chat_sessions.reasoning_effort`（会话级，跟会话走）；下拉里模型与推理等级
  两个分区并存，选完不自动收起；
- **透传**：发消息时若会话设置了等级，主回答加 `reasoning_effort` 参数（未设置不传，
  模型默认）。图片自动路由到视觉模型时同样生效。

## 二、对话图片上传

- 输入框左侧新增「上传图片」按钮（ImagePlus 图标）→ 选择本地图片 → 走与粘贴相同的
  压缩链路（1024px/JPEG 0.8）→ 预览 → 发送（自动路由视觉模型）。
