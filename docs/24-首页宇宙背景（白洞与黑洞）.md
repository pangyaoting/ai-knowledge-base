# 阶段 4+：首页宇宙背景——白洞 / 黑洞 Canvas 物理引擎

> 一句话：首页背景不再是一张"贴图"，而是一个 **Canvas 实时物理引擎**——
> 暗黑模式是黑洞（开普勒吸积盘 + 光子环 + 引力透镜 + 事件视界），
> 浅色模式是白洞（黑洞的时间反演：物质向外喷射；原"同尺寸白核"已删除——核心半径历经 R→0.27R→0.12R 点、最终不画，coreR 仅作互动判定半径），
> 核心位于页面下方避开文字，粒子铺满整页，主题切换时两套场景**交叉淡入**，
> 全程鼠标互动（核心跟随视差 / 能量斥力偏转粒子）。

> ⚠️ **本笔记为初版设计快照，白洞核心实体已全部删除**：后续 20+ 轮视觉打磨见 docs/35-首页宇宙视觉打磨.md——
> 白洞的白核 / 黑环 / 星环 / 外晕 / 光晕已全部删除，当前浅色模式 = 径向渐变天空（核心深蓝 #3a548f → 边缘白）+ 喷流粒子 + 光尘 + 点缀星，无任何核心实体；黑洞盘粒子 1800 + 吸入 240。

## 一、需求与决策记录（为什么做、为什么这么做）

### 1.1 需求演进链：从"简陋"到"白洞 / 黑洞"（用户逐轮反馈）

| 轮次 | 用户原话（要点） | 落地 |
|---|---|---|
| 1 | 项目外观是否过于简陋 | 全局视觉升级：靛蓝 AI 风 + 暗色模式（`54fb299`） |
| 2 | 把紫色换成蓝色 | 主色改纯蓝，色相 221，去紫色残留（`5d41332`） |
| 3 | 加多点动画，页面背景炫酷点 | 动效体系：入场动画、光斑漂移、路由过渡（`6dee430`） |
| 4 | 页面切换不要向上弹出，首页背景动态酷炫就行 | 路由过渡改纯淡入；首页极光背景（`21faa94`） |
| 5 | 以星空为背景，动态特效拉满 | 星空 CSS 版：星星/流星/星云（`5386ed9`） |
| 6 | 还不够炫酷，像塑料，去看看别人的网站 | 弃 CSS，改 **Canvas 粒子引擎**（固定深色星空） |
| 7 | 首页的浅色背景我不喜欢 | 固定深色星空，不随主题 |
| 8 | **浅色模式用白洞，暗黑模式用黑洞，要震撼、要动态、要互动、要真实** | 本版：双模式物理引擎（`d116f00`） |
| 9 | 背景与文字重叠，往下移；白洞比黑洞太大，大小一致样式相反；粒子增多铺满整页 | 核心下移 0.74h；白核=视界同半径、反光子环同位；独立倾角粒子云铺满整页 |

> 第 8 轮是关键转折：用户之前要"固定深色星空"，但最终明确要**两种模式都有**——
> 浅色也要惊艳（白洞），所以主题联动回归，且用"时间反演"思路让两种模式互为镜像。

### 1.2 方案对比：CSS 贴图 vs Canvas 引擎（用户选定：Canvas）

| 维度 | CSS 渐变/贴图（旧方案） | **Canvas 2D 粒子引擎（选定）** |
|---|---|---|
| 真实感 | 静态渐变 + 少量 CSS 动画，被评价"像塑料" | 开普勒轨道/多普勒聚束/引力透镜，物理级真实 |
| 动态 | 有限的关键帧动画 | 每帧演化：粒子绕行、内落/喷射、流星、脉动 |
| 互动 | 几乎无 | 核心跟随鼠标、粒子受鼠标斥力 |
| 主题切换 | 两套 CSS 硬切 | 两套场景透明度**交叉淡入** |

### 1.3 三个写进代码的硬决策

1. **随主题双模式**：暗黑→黑洞（blend 0）、浅色→白洞（blend 1），切换时 blend 每帧插值 0.04（约 0.7s 交叉淡入）；
2. **核心下移避开文字**：核心 y = `h * 0.74`（页面下方），欢迎区/卡片/引导文字不再与核心重叠；
3. **白洞与黑洞同尺寸、样式相反**（**已删除，历史快照**）：白核半径 = 视界半径 R、反光子环 1.42R 白环、光晕 2R 等白洞核心实体
   均已不再绘制——曾经历白环 → 黑环 → 最终全部删除（详见 docs/35），coreR 仅保留为互动判定半径。

## 二、系统设计（HomeCosmos.vue）

### 2.1 场景结构：两套独立场景 + 交叉淡入

```
每帧：更新黑洞场景 + 更新白洞场景（两套始终演化，切换回来立即可见）
      → blend += (targetBlend - blend) * 0.04
      → 若 blend < 0.995 画黑洞(alpha=1-blend)；若 blend > 0.005 画白洞(alpha=blend)
```

### 2.2 粒子体系：每粒子独立倾角，铺满整页

- 传统做法是"整盘一个倾角"（盘面薄薄一条带）。要"铺满整页"，改为**每粒子独立 tilt**：
  - 盘内（r<1.05）：tilt ≈ 盘面倾角 inc（0.22~0.39），保持薄盘；
  - 外围云（r>1.05）：tilt 随机 0.15~1，粒子在三维壳层上分布，铺满整页。
- 半径范围 r = 0.075~1.9（× diskR=0.46·min(w,h)），粒子规模：**黑洞盘 1800 + 吸入 240 / 白洞 2400**（另光尘 200、星 260/60）。
- 云↔盘过渡：黑洞外围云粒子落入盘面时收拢到薄盘倾角；白洞内区喷流喷出后散开成外围云。
- 画布 `dataset.particles = "1800,2400"` 暴露计数（黑洞盘粒子数,白洞喷流粒子数，不含 infall/光尘/星），供自动化测试断言粒子规模。

### 2.3 黑洞（暗黑模式）——五要素

| 要素 | 实现 |
|---|---|
| 事件视界 | 纯黑圆（R = 0.062·min(w,h)），边缘画红移暗环 |
| 光子环 | 1.42R 处橙色细亮环（径向渐变，峰值白热） |
| 吸积盘 | 开普勒轨道 `ω = K/r^1.5`（K=0.00158），径向内落 vr<0；颜色内白热→金黄→橙→品红→蓝紫；速度拖尾随角速度拉长 |
| 多普勒聚束 | 迎面侧更亮 `dopp = 1 + 0.5·sinθ`（盘前侧亮） |
| 引力透镜 | 背景星靠近黑洞时按 `β' = β + R_E²/β` 向外弯曲（爱因斯坦环效果） |

绘制顺序（关键）：盘背侧 → 事件视界 + 光子环 → 盘前侧（叠在视界下缘），得到"盘从视界前后穿过"的真实观感。

### 2.4 白洞（浅色模式）＝ 黑洞的时间反演

- **同尺寸相反样式**（**已删除**）：白核 = 视界半径 R 的纯白圆（脉动 ±6%）；反光子环 = 1.42R 白环；外晕收窄到 2R——
  白环 → 黑环 → 最终全部删除，当前无任何核心实体（见 docs/35）；
- 物质行为反转：粒子向外喷射（vr>0，每帧 ×0.9998 减速），内区喷流 → 散开成外围云 → r>1.9 消散重喷；
- 背景改为以白洞位置为圆心的径向渐变天空（核心深蓝 #3a548f → #7693c6 → #c0d4ef → #eef4ff → 边缘白 #ffffff）
  （激波环已删 `5fcc45e`、无光晕射线，漂浮光尘保留）；
- 光尘/粒子走视差，增强景深。

### 2.5 互动

- 核心跟随鼠标：`holeX = w/2 + mx·0.09·min(w,h)`、`holeY = 0.74h + my·0.09·min(w,h)·0.7`（鼠标先平滑插值）；
- 白洞：鼠标靠近核心时粒子受"能量斥力"（220px 内按距离加权推离并加速喷出）。
- **互动已演进（详见 docs/35）**：黑洞局部引力 + 悬停核心全体吞噬（vr 下限 −0.025）；白洞悬停核心全体加速爆发（vr 封顶 0.028）；`mouseActive` 门控（首次 mousemove 前互动失效）；粒子飞出屏幕 20px 才重生。

## 三、前端联动（Home.vue）

- `<HomeCosmos />` 常驻背景层（`pointer-events-none absolute inset-0`），Canvas 自绘背景，删除旧 `.starfield` CSS 与星云光斑；
- 内容层颜色**随主题**：`const { isDark } = useTheme()` 条件类——
  黑洞深底用浅色文字（`text-slate-50/300/400`、卡 `bg-slate-900/70`），白洞亮底用深色文字（`text-slate-900/600/500`、卡 `bg-white/75`）；
- 服务状态徽章用 computed 按主题切换深浅配色。

## 五、经验与坑（这个功能教会我的）

1. **场景映射写反**：`targetBlend = isDark ? 1 : 0` 让暗黑显示了白洞——先想清楚"0=黑洞、1=白洞"再写映射；
2. **白洞"太大"的真相不是核心，是光晕**：glow 6R 一大团 → 收窄 2R，视觉尺度立刻与黑洞一致；
3. **白底上的白色不可见**：白洞最初背景接近纯白（中心 255 vs 背景 251，只差 4 个亮度级）——改成亮蓝空，白色核心/射线/环才有对比；
4. **粒子单像素采样会"漏"**：吸积盘粒子是离散的，单像素断言忽明忽暗——改 16~40px 区域均值；
5. **顺手修了一个真崩溃**：`email-code.service` 里 `verifyOnly()` 漏 `await`，验证码错误抛出的异常变成未处理 rejection **打崩整个后端进程**（自测时真实撞上）——补 await 后错码正常返回 400（独立提交 `76450d6`）；
6. **性能控制**：两套场景每帧全量演化（黑洞盘 1800 + 吸入 240 + 白洞 2400 + 光尘 200 + 星 260/60 ≈ 5000 粒子），DPR 上限 2，内层光晕只画近核粒子，桌面端保持流畅。

## 六、面试一句话

"首页背景是一个双模式 Canvas 物理引擎：暗黑模式渲染黑洞（开普勒吸积盘、多普勒聚束、引力透镜、事件视界遮挡），浅色模式渲染它的时间反演白洞（白核等核心实体已删，见 docs/35），两套场景每帧独立演化、主题切换交叉淡入，鼠标可互动——用像素级自动化断言验证了'中心视界纯黑、光子环明亮'的物理结构。"
