# AI 服务申请指南（硅基流动 + DeepSeek）

> 本项目需要两个 AI 服务的 API Key：
> 1. **硅基流动（SiliconFlow）**：Embedding 向量化 + bge-reranker 重排用（阶段 2/4），免费额度大
> 2. **DeepSeek**：对话问答用（阶段 3），价格极低
>
> 两个都是国内服务，注册简单、支付宝实名即可，学生零门槛。

---

## 1. 硅基流动 SiliconFlow（先申请这个，阶段 2 就要用）

官网：https://cloud.siliconflow.cn

### 1.1 注册

1. 打开 https://cloud.siliconflow.cn ，点右上角「注册」
2. 支持手机号 / 邮箱 / 微信扫码注册（推荐微信，最快）
3. 注册后进入控制台

### 1.2 领取免费额度

- 新用户注册一般送 **14 元免费额度**（BGE-M3 embedding 模型 100 万 token 约 0.5 元，够你测试几百次）
- 控制台首页能看到「余额」和「免费额度」
- **注意**：部分免费额度有有效期（通常 1-3 个月），用之前看一眼

### 1.3 获取 API Key

1. 控制台左侧菜单 → 「API 密钥」（或 API Keys）
2. 点「新建 API 密钥」→ 复制 `sk-` 开头的字符串
3. **保存好，只显示一次**，丢了要重新生成

### 1.4 验证 Key 能用（测试命令）

把下面命令里的 `sk-你的key` 换成你的 key，在 PowerShell 执行：

```powershell
$body = @{
  model = "BAAI/bge-m3"
  input = @("测试一下")
} | ConvertTo-Json -Depth 3
Invoke-RestMethod -Uri "https://api.siliconflow.cn/v1/embeddings" -Method Post -Headers @{Authorization="Bearer sk-你的key"; "Content-Type"="application/json"} -Body $body
```

返回里有 `embedding` 字段（一串 1024 个数字）就是成功。

### 1.5 写入项目 .env

打开项目根目录的 `.env`（用 VS Code 或记事本），找到：

```env
SILICONFLOW_API_KEY=sk-你的key
```

把 `sk-你的key` 换成你刚申请的真 key，保存。

> ⚠️ 安全提醒：`.env` 已经被 `.gitignore` 排除，不会提交到 GitHub。但**不要在聊天里把 key 发给别人**，也不要截图发到网上。面试展示时可以现场申请临时 key 或只展示部分字符。

> 另外，硅基流动还用于**重排模型 BAAI/bge-reranker-v2-m3**（混合检索的 Rerank 环节，见 docs/16），同一平台、同一把 key 即可调用。

## 2. DeepSeek（对话模型 —— 现已改为 BYO，无需申请）

> **⚠️ 2026-08 现状：对话已改为 BYO（Bring Your Own）**——用户在「模型配置」页绑定自己的 Key（后端 ModelConfig AES-256-GCM 加密落库，见 docs/20），
> `.env` 里的 `DEEPSEEK_API_KEY` **已不用于对话**。以下申请步骤仅供了解（想自用可自行注册）。

官网：https://platform.deepseek.com

### 2.1 注册 + 充值（仅自用参考）

1. 打开 https://platform.deepseek.com ，手机号注册
2. 左侧「API Keys」→ 新建 key（`sk-` 开头）
3. 充值：最低充 ¥10（DeepSeek 对话模型约 ¥1-2 / 百万 token，¥10 够你测试几百轮对话）

### 2.2 写入 .env（不再用于对话，仅保留作参考）

```env
DEEPSEEK_API_KEY=sk-你的key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
```

## 3. 常见问题

| 问题 | 解决 |
|------|------|
| 调用报 401 | key 复制错了 / key 过期，去控制台重新生成 |
| 调用报 429 | 限流了，稍等几秒重试（我们的代码里做了指数退避重试） |
| 报"余额不足" | 免费额度用完了，充值或换个新号 |
| Embedding 报"model not found" | 模型名写错，确认是 `BAAI/bge-m3` |
