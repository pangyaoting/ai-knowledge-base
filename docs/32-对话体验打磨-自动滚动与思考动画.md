# 32 · 对话体验打磨：发送自动滚动 + 思考动画圆点

## 背景

Chat 页对齐 ChatGPT 交互标准的两处体验问题：

1. **发送新问题不滚到底**：自动滚动有"用户上翻历史时暂停跟随"的保护，但发送新问题时没强制回到底部——用户翻过历史后发新问题，看不到自己刚发的内容。
2. **思考等待时显示三个静态点**：流式回答未收到首个 token 前渲染 `renderMarkdown('…')`，是三个静态的点，像卡住了一样。

## 改动（apps/web/src/views/Chat.vue）

### 1. 发送新问题强制滚到底

`handleSend` 乐观渲染用户消息后：

```ts
// 发送新问题时强制滚到新问题所在位置（即使用户刚才在翻历史，也要回到最新）
autoScroll = true;
await nextTick();
const el = messageContainer.value;
if (el) el.scrollTop = el.scrollHeight;
```

- 重置 `autoScroll` 并立即滚动：**发新问题永远回到最新**；
- 回答流式期间若用户上翻历史，`onMessageScroll` 仍会把 `autoScroll` 置回 false，自动跟随暂停——翻历史读回答不被强拉。

### 2. 思考动画圆点替换静态省略号

- 等待首个 token（`streamContent` 为空）时，渲染**三个跳动的圆点**气泡 + "思考中"文字（ChatGPT 风格动画）：
  - `.thinking-dot` 6px 圆点，`animation: thinking-bounce 1.2s infinite ease-in-out`；
  - `nth-child(2)/(3)` 分别延迟 0.15s / 0.3s，形成波浪式跳动；
  - 关键帧：0%/80%/100% 原位半透明，40% 上移 5px 不透明。
- 收到首个 token 后自动切换回 Markdown 渲染；
- 检索到来源时的提示文案末尾去掉静态 "..."（动画圆点已承担等待语义）。

### 3. 检索思考中：蓝色光条文字 + 右侧计时（替代圆点）

用户进一步要求"文字 + 光条 + 计时"风格，圆点方案废弃：

- **蓝色文字** `检索思考中...`（`#3b82f6`，text-sm 字重 500）；
- **白色光条从左到右循环扫过**：双层文字叠加实现——
  - 底层 `.thinking-shimmer-base`：纯蓝色文字；
  - 上层 `.thinking-shimmer-overlay`：绝对定位同文案，`background: linear-gradient(90deg, transparent, #fff 44%, #fff 56%, transparent)`（白峰收窄在中央，细光条两侧渐隐，避免大片白光）+ `background-size: 200% 100%` + `background-clip: text`；
  - `animation: shimmer-sweep 1.5s linear infinite`，`background-position` 从 `110% 0` → `-10% 0`：行程只比文字宽一点——光条刚扫出右端（不可见），下一圈就从左端接上，循环无缝、几乎无空白停顿（避免"扫完等很久才重新出现"的断档感）；
- **右侧实时计时** `mm:ss`（`tabular-nums` 防跳动）：`handleSend` 里 `startThinkingTimer()`（setInterval 每秒 +1），`finally` / `handleStop` / `onBeforeUnmount` 里 `stopThinkingTimer()`；KeepAlive 缓存下切导航计时继续，回来时间准确。

## 交互效果

- 发送 → 立即滚到新问题；思考 → 蓝色"检索思考中..."文字 + 白色光条循环扫过 + 右侧已等待时间，不误以为卡死；首 token 到达 → 平滑切换为回答文本。
