# 阶段 4+：数据看板研究统计 + 用户头像

> 一句话：看板把**研究报告 / 自主研究**的 token 和对话分开统计（总消耗含研究、
> 近 7 日图表拆「对话 / 研究」两条线）；用户头像支持**自己上传**（未上传显示邮箱首字母兜底）。

## 一、数据看板

- **Token 总消耗卡片** = 对话（输入+输出）+ 研究报告 + 自主研究，卡片内三行分解；
- **近 7 日 Token 图**：两条堆叠柱——「对话」（chat_messages 流式 usage）、
  「研究」（reports + agent_tasks 的 tokens_used 按天聚合，SQL UNION ALL）；
- 后端 `stats.service`：`daily` 增加 `researchTokens`，`tokens.total` 改为全量。

## 二、用户头像（自上传，非邮箱头像）

- **方案取舍**：不用 Gravatar（国内访问不稳定、需邮箱先注册）；改为**自己上传** +
  未上传时显示邮箱首字母占位（纯前端生成，无外部依赖）；
- 后端：`POST /api/user/avatar` 收 base64 dataURL（png/jpeg/webp，≤2MB），
  存 `uploads/avatars/{userId}.{ext}`（固定名自动覆盖旧头像），`User.avatar` 更新为
  `/avatars/{userId}.{ext}`；`/avatars` 由 main.ts 手写静态处理器提供
  （与知识库附件隔离：附件保持鉴权，头像公开可访问）；
- 前端：个人中心资料区「上传/更换头像」，压缩裁剪成 200×200 方形 JPEG；
  侧边栏用户按钮与菜单同步显示头像；vite dev 加 `/avatars` 代理。
