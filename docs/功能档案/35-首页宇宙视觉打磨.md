## 二、最终实现速览（当前 HomeCosmos.vue）

### 2.1 黑洞（暗色模式）
- **吸积盘**：1800 粒子，开普勒轨道 + 缓慢内落（vr −0.0001~−0.00034），`diskColor` 内白热→金黄→橙→品红→蓝紫；
- **吸入粒子 infall**：240 个，径向快速坠入（默认 −0.0007~−0.0015，重生重置），与盘同款配色/多普勒/光晕；
- **鼠标互动**：局部（`localPull`，约 0.16·min(w,h) 半径）粒子加速旋转 + 加速吸入；悬停核心（2.5R 内平滑增强）→ 全部粒子加速旋转、加速坠入视界（vr 下限 −0.025 防爆炸）。

### 2.2 白洞（浅色模式，已删核心实体）
- **背景**：以白洞位置为圆心的径向渐变，核心周围深蓝 `#3a548f`（0.18 半径内）→ 快速过渡 → 边缘白，文字可读；
- **喷射粒子**：2400 个，默认缓速 0.0035~0.0065（约 4.5s 一轮），`whJetColor` 奶油暖白 `[255,246,224]` → 淡蓝 → 蓝紫 → 深蓝紫 `[72,60,202]`；
- **鼠标互动**：悬停核心位置（2.5·coreR 内，coreR=0.12R 很小）全体加速，封顶 vr 0.028（约 1s 一轮爆发）；能量斥力保留；
- **连续性**：`age` 淡入（0.25s 涌现）→ 全程饱满不渐隐 → **飞出屏幕 20px 才循环重生**（屏幕内永不消失）；
- **无核心实体**：白核、反光子环（黑环）、星环、外晕、核心光晕全部删除——只有背景 + 粒子 + 光尘 + 点缀星。

### 2.3 互动对称设计（面试可讲）
| | 黑洞（暗色） | 白洞（浅色） |
|---|---|---|
| 默认 | 缓慢吸入 | 缓速喷射 |
| 悬停核心 | 全体加速吞噬 | 全体加速爆发 |
| 颜色 | 内白热 → 外蓝紫 | 内奶油暖白 → 外深蓝紫 |
| 生命周期 | 坠入视界即重生 / 出屏重生 | 出屏重生 |
| 核心实体 | 事件视界 + 光子环 + 吸积盘 | （已删，纯喷流） |

## 三、关键决策与原理

1. **"不明显"的根因是对比度**：白色粒子在浅蓝天空上色差仅几个亮度级 → 给白洞上深色背景（核心深蓝径向渐变），白色粒子在深蓝底、深蓝紫粒子在白底，全程互补；
2. **颜色反复校准的教训**：暖黄炽白在深蓝底被感知为"赤橙/滚烫"（用户明确要过赤橙又删掉）；最终"奶油暖白起点"是刺眼与观感的折中——**先问清用户要暖还是要冷，别自作主张**；
3. **连续性 = 重生发生在不可见处**：`age` 淡入让核心重生点 alpha≈0；外圈不渐隐则必须**飞出屏幕才循环**；
4. **初始鼠标在屏幕中央会误触发互动**：粒子铺满整页 + 鼠标初始 (0.5,0.5) → `mouseActive` 门控修复；
5. **"删核心实体"的收敛过程**：用户从"核心缩小（0.72→0.27→0.12R）"一路走到"全删"——每一步都先确认观感，删除比反复缩小更符合最终诉求；
6. **白洞=黑洞时间反演**：互动参数一一对应（2.5R 阈值、vr 封顶、生命周期），两套互为镜像。

## 四、坑（本轮新增）

1. **esbuild 数字字面量改写**：`0.0028` 转译成 `28e-4`、变量 `r1` 可能被重命名（`r12`）——验证热更新内容要用语义标记（如 `whJetColor`/`globalPull`），别匹配具体数字/短变量名；
2. **vite watcher EBUSY**：编辑工具经临时目录写文件触发 `EBUSY ... tmpdir`，vite 崩溃——改完文件后需重启（后台 `npx.cmd vite --host`，需完整权限）；
3. **vr 累积爆炸**：鼠标持续压核心时 `vr` 每帧累加，需设下限/封顶（黑洞 −0.025、白洞 +0.028），重生时重置默认值；
4. **换色板要清引用**：删 `WH_JET_PALETTE` 后必须同步清 `WhDiskParticle.color` 字段与光尘颜色，否则 `vue-tsc` 报未定义；
5. **"环带"歧义**：用户先后用"白色环带"指代星环与反光子环——改错一次（`fc33544` 误改星环）后经用户澄清才改对，**涉及多个同名视觉元素时先确认指代**；
6. **GitHub 网络抖动**：推送偶发 `Failed to connect to github.com:443`，等 30s 重试即可（曾误判"Everything up-to-date"实际未推送，需 `git rev-parse` 对比本地/远端确认）。
