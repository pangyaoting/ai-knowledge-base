# 34 · 补测试：从 0 测试到 37 个单测全绿

## 背景

此前全项目 **0 个测试**（82 个后端文件 + 53 个前端文件全靠手动点页面验证），面试官视角 = "课程设计"；补上测试 = 工程化闭环（本地 `pnpm test` 一键跑 + CI 自动验证）。

## 原则

**只测纯逻辑，不测 UI/数据库**——投入产出比最高的部分，且都是面试能讲的核心算法。

## 后端 Jest（apps/server）

- 装 `jest + ts-jest + @types/jest`；`jest.config.cjs`（rootDir=src，只跑 `*.spec.ts`）
- **text-splitter.spec.ts（9 个用例）**：分块算法——
  - 500 字内整块返回；超长切多块且每块 ≤ chunkSize+overlap（重叠尾巴拼新块前）
  - 重叠尾巴不丢边界内容（`chunks.join('')` 可找回"边界词"）
  - 按段落/句号自然边界切、句号不丢；空文本返回空
  - splitCode：prefix 拼到每块开头；超长单行按窗口硬切不产生巨无霸块；短代码整块返回；超长代码切成多块
- **rrf.spec.ts（6 个用例）**：混合检索融合——
  - 两路都命中的排在只命中一路前（`1/61 + 1/62 > 1/61`）
  - 融合分相同时向量路优先；topK 截断；只依赖排名不依赖分数；空输入；RRF_K=60
  - 顺带把 `rrfMerge` 从 rag.service.ts 提取到 `rrf.ts`（纯函数可测 + 关注点分离）

## 前端 Vitest（apps/web）

- 装 `vitest@^2.1.9`（v4 需要 vite 6，项目是 vite 5）+ `jsdom`；`vite.config.ts` 加 `test` 字段
- **doc-tree.spec.ts（7 个用例）**：目录树构建（根文件/嵌套路径/文件夹统计）、扁平化摊平（深度递增）、文件夹计数/收集
- **file-icons.spec.ts（8 个用例）**：扩展名提取/配色/图标类别映射
- **markdown.spec.ts（7 个用例）**：渲染标题/列表、代码块自动包复制按钮、语言未知转义防注入、禁用原始 HTML、换行 `<br>`、getCopyCode 取码

## 工程化

- 根 `package.json` 加 `test` script（`pnpm --filter @app/server test && pnpm --filter @app/web test`）
- **CI（deploy.yml）check job 加两步**：`Test server (Jest)` + `Test web (Vitest)`——以后每次 push 自动跑测试，红了阻止合并
- 修复 pnpm-workspace.yaml：`@parcel/watcher` / `unrs-resolver` 的 allowBuilds 占位文本补成 `true`（否则 pnpm 11 非交互 install 失败）
