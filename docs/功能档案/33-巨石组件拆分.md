# 33 · 巨石组件拆分（前端工程化收口）

## 背景

三个前端视图文件都是"巨石组件"，前端面试官一眼就会挑：

| 文件 | 拆分前 | 拆分后（当时） | 当前（随迭代变化） |
| --- | --- | --- | --- |
| `views/Chat.vue` | 1639 行 | 约 960 行（`ac0bfd6`） | 约 844 行 |
| `views/KnowledgeDocuments.vue` | 约 1380 行 | 约 820 行（`2a17f29`） | 约 806 行 |
| `views/ResearchAgent.vue` | 约 1390 行 | 约 810 行（`e17971d`） | 约 796 行 |

## 原则

**只拆纯展示/独立子组件，状态与业务逻辑留在容器**（KeepAlive、流式、自动滚动、草稿记忆、轮询等横跨全局的状态不硬拆，避免回归风险）。

## 拆分结果

### Chat.vue → `components/chat/`

| 组件 | 职责 |
| --- | --- |
| `ChatSessionSidebar.vue` | 会话列表：搜索/选中/删除/新建/收起（props + events） |
| `ChatMessageItem.vue` | 单条消息：图片/文件 chips/气泡/Markdown/复制/分支 |
| `ChatSourcePanel.vue` | 引用来源面板（知识库 + 网络，details 折叠） |
| `ChatThinkingBar.vue` | 检索思考中动画（蓝色光条文字 + 右侧计时） |
| `ChatMessageInput.vue` | 输入区：模型下拉/推理等级/图片文件上传/发送停止（defineModel + events + expose focusTextarea） |
| `ChatKbPickerModal.vue` | 新建对话/改问答范围弹窗 |

### KnowledgeDocuments.vue → `components/knowledge/` + utils

| 文件 | 职责 |
| --- | --- |
| `utils/file-icons.ts` | 扩展名配色/图标类别（纯函数） |
| `utils/doc-tree.ts` | 目录树构建/扁平化/计数/收集（纯函数） |
| `components/knowledge/DocCodeEditor.vue` | 整页代码编辑（行号/高亮/Tab 缩进/同步滚动） |
| `components/knowledge/DocTableRow.vue` | 表格行：文件夹行（展开/重命名/删除）+ 文件行（编辑/下载/替换/删除），搜索模式与树模式共用 |

### ResearchAgent.vue → `components/research/`

| 组件 | 职责 |
| --- | --- |
| `AgentTaskSidebar.vue` | 任务列表：选中/删除/新建 |
| `AgentCreateForm.vue` | 新建表单：模式/目标/时间窗/预算档位（v-model 双向绑定） |
| `AgentExtendModal.vue` | 续时/加预算弹窗 |
| `AgentReportView.vue` | 报告渲染：摘要/引言/方向卡片折叠/结论/来源，含"全部展开/收起" |

## 顺带优化

- **markdown-body 排版样式全局化**：三份几乎相同的 scoped 副本（Chat/Research/ResearchAgent 各 ~100 行）合并进 `styles/index.css`，全站统一，后续页面直接可用。
- 每个子组件都 `defineOptions({ name })`，配合 KeepAlive 缓存与 Vue DevTools 可读。

## 验证

- `vue-tsc --noEmit` 通过
- `pnpm lint` 全绿（server + web 0 error）
- `pnpm --filter @app/web build` 通过
- 交互行为保持不变（纯模板迁移 + 事件上抛，无逻辑改动）
